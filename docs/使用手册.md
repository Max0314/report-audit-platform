# 硬件研发部测试报告审核平台

## 一、平台概述

硬件研发部测试报告审核平台是一套专为硬件测试报告设计的智能审核与数据分析系统，采用前后端分离架构，支持本地部署，确保研发数据安全。

### 核心特性

- **双入口设计**：智能审核与智能分析两个独立入口
- **AI 能力集成**：DeepSeek API 实现错别字与语义检测
- **高度可拓展**：模块化设计、配置与代码分离
- **本地部署**：数据纯本地处理，保护隐私

## 三、快速开始

### 3.1 环境要求

- Python 3.10+
- 现代浏览器（Chrome/Edge/Firefox）

### 3.2 安装步骤

```bash
# 1. 克隆或下载项目

# 2. 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate  # Windows

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置 DeepSeek API（可选，但推荐）
# 编辑 .env 文件，填入您的 API Key
DEEPSEEK_API_KEY=your-api-key-here

# 5. 启动服务
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 6. 访问平台
# 浏览器打开 http://localhost:8000
```

## 四、使用指南

### 4.1 入口A：智能报告审核

1. 访问智能审核页面
2. 上传测试报告 Excel 文件
3. 点击「开始审核」
4. 查看审核结果

**审核功能**：
- 错别字智能检测（AI 驱动）
- 跨 Sheet 关键信息一致性校验
- 测试值与判定结果逻辑校验
- 测试项目完整性校验
- 日期合法性校验

### 4.2 入口B：测数聚合分析

1. 访问智能分析页面
2. 批量上传多个同测试方案的报告
3. 点击「开始分析」
4. 查看统计数据和可视化图表

**分析功能**：
- 批量数据自动聚合
- 统计指标计算（最大值、最小值、平均值、标准差、中位数）
- 交互式图表展示（直方图、散点图、箱线图、趋势图）

## 五、配置说明

### 5.1 配置文件位置

- 主配置：`config/settings.yaml`
- 环境变量：`.env`

### 5.2 关键配置项

```yaml
# AI 服务配置
ai_service:
  api_key: ""        # DeepSeek API Key

# 文件存储配置
file_storage:
  max_file_size: 104857600  # 100MB
  allowed_extensions:
    - .xlsx
    - .xls

# 验证规则
validation_rules:
  standard_test_items:  # 标准测试项目清单
  test_value_rules:     # 测试值判定规则

# 分析配置
analysis:
  statistics:          # 统计指标
  chart_types:         # 图表类型
```

## 六、扩展指南

### 6.1 新增测试项目

编辑 `config/settings.yaml` 中的 `validation_rules.standard_test_items`：

```yaml
validation_rules:
  standard_test_items:
    新增类别:
      - 新增测试项1
      - 新增测试项2
```

### 6.2 新增测试值规则

编辑 `config/settings_rules.test_value_rules`：

```yaml
test_value_rules:
  新增参数:
    min: 0
    max: 100
    unit: "单位"
```

### 6.3 新增 AI 服务

1. 在 `app/services/` 创建新的 AI 服务类
2. 实现统一的检查接口
3. 在配置中切换服务提供商

### 6.4 新增图表类型

在 `app/services/analysis_service.py` 中添加新的图表生成方法。

## 八、常见问题

### Q1: AI 错别字检查功能不可用？

A: 请确保已正确配置 DeepSeek API Key，编辑 `.env` 文件。

### Q2: 上传文件大小有限制吗？

A: 默认 100MB，可在配置文件中修改 `file_storage.max_file_size`。

### Q3: 支持哪些 Excel 格式？

A: 支持 `.xlsx` 和 `.xls` 格式。

### Q4: 如何查看日志？

A: 日志文件位于 `logs/` 目录。
